## 1. 本讲核心问题

- 特征从一个变成 $n$ 个之后，$h$、$J$、梯度下降分别怎么改？
- 为什么要把 $\theta_0,\theta_1$ 逐个更新，改写成**一次更新整个向量** $\theta$？
- 特征量级差太多会发生什么？**特征缩放**为什么能救回来？

---

## 2. 先记住这四句话（本讲骨架）

1. **模型**：$h_\theta(x)=\theta_0+\theta_1x_1+\cdots+\theta_nx_n$，约定 $x_0=1$ 后可写成 $h_\theta(x)=\theta^\top x$。
2. **向量化更新**：$\boxed{\theta := \theta - \dfrac{\alpha}{m}X^\top(X\theta-y)}$，一行顶 $n+1$ 个更新式。
3. **维度自检**：$X$ 是 $m\times(n+1)$，$\theta$ 是 $(n+1)\times1$，$X\theta-y$ 是 $m\times1$，$X^\top$ 乘上去得到 $(n+1)\times1$，和 $\theta$ 同形 ✅
4. **特征缩放**：把各特征压到相近量级（约 $-1\le x\le 1$），等高线从细长椭圆变回圆，$J$ 的下山路径不再左右震荡。

**需要对齐的记号**（快刷时确认这几条能对上号即可，不必逐分钟看）：

| 概念 | 记号 | 要点 |
|---|---|---|
| 矩阵的维数 | $A\in\mathbb{R}^{m\times n}$ | $m$ 行 $n$ 列；$A_{ij}$ = 第 $i$ 行第 $j$ 列的元素 |
| 向量 | $x\in\mathbb{R}^{n}$ | 默认指**列向量**，写 $x=\begin{bmatrix}x_1\\ \vdots\\ x_n\end{bmatrix}$ |
| 矩阵-向量乘法 | $A(m\times n)\cdot x(n\times1)=y(m\times1)$ | **前者的列数必须等于后者的行数**；$y_i=\sum_{j}A_{ij}x_j$ |
| 矩阵-矩阵乘法 | $A(l\times m)\cdot B(m\times n)=C(l\times n)$ | 中间维数必须相等；$C$ 取 $A$ 的行数、$B$ 的列数 |
| 乘法不满足交换律 | $AB\ne BA$（一般情况） | 满足结合律 $(AB)C=A(BC)$ |
| 单位矩阵 | $I$，$I_{ii}=1$、其余为 0 | $AI=IA=A$，相当于数字里的 1 |
| 逆矩阵 | $A^{-1}$，满足 $A^{-1}A=AA^{-1}=I$ | **只有方阵才可能有逆**；不存在逆的叫**奇异矩阵**（singular / degenerate） |
| 转置 | $A(m\times n)\to A^\top(n\times m)$ | 行列互换：$(A^\top)_{ij}=A_{ji}$ |

**必须记住的两条性质**（向量化推导要用）：

$$(AB)^\top = B^\top A^\top \qquad (A+B)^\top = A^\top + B^\top$$

> **⚠️ 易错点**：$(AB)^\top$ 是 $B^\top A^\top$，**顺序要反过来**。这条记错，后面的推导会对不上维度。

## 4. 多维特征（课时 4-1《多功能》，8:23）

房价例子升级：不再只看面积，而是同时用「面积 / 卧室数 / 楼层 / 房龄」四个特征预测价格。

| 记号 | 含义 |
|---|---|
| $n$ | 特征个数（上例中 $n=4$） |
| $m$ | 训练样本数 |
| $x^{(i)}$ | 第 $i$ 个样本，是一个**向量** $\in\mathbb{R}^{n}$ |
| $x^{(i)}_j$ | 第 $i$ 个样本的**第 $j$ 个特征** |

于是假设函数从一条直线变成一个超平面：

$$h_\theta(x)=\theta_0+\theta_1x_1+\theta_2x_2+\cdots+\theta_nx_n$$

**关键技巧：约定 $x_0=1$**（人为补一个恒为 1 的第 0 维），则：

$$x=\begin{bmatrix}x_0\\x_1\\ \vdots\\ x_n\end{bmatrix}\in\mathbb{R}^{n+1},\quad
\theta=\begin{bmatrix}\theta_0\\ \theta_1\\ \vdots\\ \theta_n\end{bmatrix}\in\mathbb{R}^{n+1}
\quad\Longrightarrow\quad \boxed{h_\theta(x)=\theta^\top x}$$

加了 $x_0=1$ 这维后，截距项 $\theta_0$ 就和其他 $\theta_j$ 一样，不用再单独处理——这是后面所有向量化的前提。

> **与 lecture02 对上号**：lecture02 的 $h_\theta(x)=\theta_0+\theta_1x$ 就是 $n=1$ 的特例。今天把它推广到任意 $n$。

## 5. 多元梯度下降法（课时 4-2，5:05）

形式完全同构，只是下标从 $j=0,1$ 变成 $j=0..n$：

$$J(\theta)=\frac{1}{2m}\sum_{i=1}^{m}\big(h_\theta(x^{(i)})-y^{(i)}\big)^2$$

$$\theta_j := \theta_j - \alpha\frac{1}{m}\sum_{i=1}^{m}\big(h_\theta(x^{(i)})-y^{(i)}\big)\,x^{(i)}_j \qquad (j=0,1,\dots,n)$$

当 $j=0$ 时，$x^{(i)}_0\equiv 1$，式子退化成 lecture02 里 $\theta_0$ 的更新式，自洽 ✅

> 同步更新（simultaneous update）的要求**不变**——所有 $\theta_j$ 必须基于同一份旧 $\theta$ 计算。

## 6. 向量化（今日核心动作）

把上面 $n+1$ 条更新式压成一行。先定义三个对象：

$$X=\begin{bmatrix}(x^{(1)})^\top\\ (x^{(2)})^\top\\ \vdots\\ (x^{(m)})^\top\end{bmatrix}\in\mathbb{R}^{m\times(n+1)}
\quad(\text{每行一个样本}),\qquad
\theta\in\mathbb{R}^{(n+1)\times1},\qquad
y=\begin{bmatrix}y^{(1)}\\ \vdots\\ y^{(m)}\end{bmatrix}\in\mathbb{R}^{m\times1}$$

**手推区**：顺着下面四步走一遍，每一步都检查维度。

**第 1 步｜批量算预测**：$h = X\theta$，形状 $m\times(n+1)\ \cdot\ (n+1)\times1 = m\times1$，第 $i$ 行正好是 $h_\theta(x^{(i)})$ ✅

**第 2 步｜批量算误差**：$e = X\theta - y$，形状 $m\times1$，第 $i$ 项是 $h_\theta(x^{(i)})-y^{(i)}$ ✅

**第 3 步｜把求和变成矩阵乘法**——这是最关键的一步：

$X^\top$ 的第 $j$ 行是第 $j$ 个特征在**全部样本**上的取值 $[\,x^{(1)}_j,\ x^{(2)}_j,\ \dots,\ x^{(m)}_j\,]$，所以

$$X^\top e\ \text{的第 } j \text{ 项} = \sum_{i=1}^{m} x^{(i)}_j\cdot e_i = \sum_{i=1}^{m}\big(h_\theta(x^{(i)})-y^{(i)}\big)x^{(i)}_j$$

这**正好**就是更新式里那个求和！于是：

$$\underbrace{X^\top(X\theta-y)}_{(n+1)\times1} \quad\Longleftrightarrow\quad n+1\ \text{条更新式各自括号里的部分}$$

维度验算：$(n+1)\times m\ \cdot\ m\times1 = (n+1)\times1$ ✅

**第 4 步｜写出成品**：

$$\boxed{\theta := \theta - \frac{\alpha}{m}X^\top(X\theta-y)}$$

> **为什么值得这么折腾**：一是代码从 $n+1$ 行循环变成一行矩阵运算；二是 NumPy / PyTorch 的矩阵乘法走的是底层 BLAS，**比手写 Python 循环快一到两个数量级**。后面模型动辄上百万参数，不向量化就没法训。

## 7. 特征缩放（课时 4-3，8:53）—— 你那个 bug 的解药

**问题长什么样**：还是房价。面积 $x_1$ 取值 $0\sim2000$，卧室数 $x_2$ 取值 $1\sim5$。

- 两个特征**量级差了几百倍** → $J$ 的等高线被拉成**又扁又长的椭圆**；
- 梯度在长轴方向的投影远大于短轴 → 下降路径左右剧烈**震荡**，要走很久才到底；
- 特征再多几个时更糟，可能直接发散。

**目标**：把所有特征压到相近范围。吴恩达的经验区间是 **$-1\le x\le 1$** 左右（放宽到 $-3\le x\le 3$ 也可以）——**不必纠结精确边界，关键是「量级相近」**。

| 做法 | 公式 | 说明 |
|---|---|---|
| 除以最大值 | $x/\max(x)$ | 最简单，但受离群点影响大 |
| 均值归一化 | $\dfrac{x-\mu}{\max-\min}$ | 结果落在 $\approx[-0.5, 0.5]$ |
| **标准化**（推荐） | $\dfrac{x-\mu}{\sigma}$ | 均值 0、标准差 1，统计性质最好，也是 sklearn 默认 |

> **⚠️ 工程上最容易漏的一步**：缩放用的 $\mu$、$\sigma$ 必须由**训练集**算出，之后**原样套用**到验证集、测试集和上线后的新样本。若用全量数据（含测试集）算 $\mu,\sigma$，等于让模型偷看了未来数据（数据泄露）。

## 9. 逐段复述自检卡（看完一段停 30 秒，合上屏幕说）

**3-1《矩阵和向量》**
- $\mathbb{R}^{m\times n}$ 里 $m$、$n$ 分别指什么？→ 行、列。
- 不加说明时，向量默认写成行还是列？→ 列向量。

**3-2《加法和标量乘法》**
- 两个矩阵能相加的前提是什么？→ 维数完全相同。
- 标量乘矩阵是怎么做的？→ 每个元素都乘上该标量。

**3-3《矩阵向量乘法》**
- $A(m\times n)$ 乘 $x$ 有结果的前提是什么？结果几维？→ $x$ 必须是 $n$ 维；结果是 $m\times1$。

**3-4《矩阵乘法》**
- 为什么一般 $AB\ne BA$？→ 连维数都可能对不上，即使都对上，逐元素求和的顺序也不同。
- $(AB)C$ 和 $A(BC)$ 相等吗？→ 相等，结合律成立。

**3-5《矩阵乘法特征》**
- 矩阵 $A$ 和单位矩阵 $I$ 相乘的结果？→ 等于 $A$ 本身（前提是维数匹配）。

**3-6《逆和转置》**
- **$(AB)^\top$ 等于什么？** → $B^\top A^\top$，顺序反过来。
- 什么样的矩阵才可能有逆？→ 方阵；奇异矩阵没有逆。

**4-1《多功能》**
- 引入 $x_0=1$ 这一维是为了解决什么问题？→ 把截距 $\theta_0$ 变成普通参数，$h$ 才能写成 $\theta^\top x$。
- $n=4$ 时，$\theta$ 到底是 4 维还是 5 维？→ **5 维**（含 $\theta_0$）。这是最常见的混淆点。

**4-2《多元梯度下降法》**
- 多元的更新式和单变量相比，改了什么？→ 只是下标从 $j=0,1$ 扩到 $j=0..n$，其余完全同构。
- $j=0$ 时式子退化成什么样？→ 因为 $x_0=1$，退化成 lecture02 里 $\theta_0$ 的更新式。

**4-3《多元梯度下降法演练 I – 特征缩放》**
- 特征量级差很多时，等高线什么形状？→ 细长的椭圆，下降路径左右震荡。
- 标准化后，对新来的样本要怎么办？→ 用训练集算出的 $\mu,\sigma$ 原样套用，不能重新算。

## 11. 疑问与待解决

（写你听课后还不懂的地方。）

今天值得记下来的两个好问题：
- $(AB)^\top=B^\top A^\top$ 为什么是这个顺序？
  → 从「$(AB)$ 的 $(i,j)$ 项 = $A$ 的第 $i$ 行点乘 $B$ 的第 $j$ 列」出发，转置后行列互换，正好对应 $B^\top$ 的行乘 $A^\top$ 的列。建议自己用 $2\times2$ 的矩阵手算一遍验证。
- 除了梯度下降，多元线性回归还有没有一步到位的解法？
  → 有，叫**正规方程**（Normal Equation）：$\theta=(X^\top X)^{-1}X^\top y$，不用迭代、不用选 $\alpha$、也不用做特征缩放。安排在 **Day5 的课时 4-6**，到时候可以和今天的方法对照着看。

## 13. 附注：01-linear-regression 发散的完整闭环

lecture02 第 14 节记录了你仓库里的失败实验：

```
第100轮:  loss=8696839.5796,            theta=[-1354.07, -1535.59]
第1000轮: loss=1.54e59,                 theta=[-5.72e27, -6.48e27]
```

当时只说「$\alpha=0.5$ 太大」。学完今天的 **4-3 特征缩放**后，诊断可以补全——这是**两个因素叠加**：

| 因素 | 对应课时 | 说明 |
|---|---|---|
| ① $\alpha$ 过大 | 2-6（lecture02） | 单看这一条，导数就被放大，容易一步跨过最优点 |
| ② 特征未缩放 | **4-3（今天）** | 原始 $x$ 在百量级，$\partial J/\partial\theta_1$ 里含因子 $x$，梯度跟着被放大上百倍 |

**① 和 ② 是相乘的**：实际更新步长 $\propto \alpha\cdot x$，两个放大因子叠起来，才导致第一步就冲到 $10^{27}$。

修法（今天已经具备全部知识，明天 Day5 的代码任务① 可以直接动手）：
1. 先对 $x$ 做标准化 $(x-\mu)/\sigma$；
2. 再把 $\alpha$ 降到 **0.01～0.05**；
3. 改完后用向量化写法重写更新式：`theta = theta - (alpha/m) * X.T @ (X @ theta - y)`，顺便去掉原来的 Python 循环。

改完 loss 应单调下降到噪声水平。**把改前 / 改后的 loss 曲线并排存进 `code-tasks/01-linear-regression/`，这就是你第一份完整的失败实验记录**——手册 Stage 3 明确要求提交，现在开始攒正好。
