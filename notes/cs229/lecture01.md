# CS229 Lecture 1：监督学习概述

## 1. 本讲核心问题

- 什么是机器学习？
- 什么是监督学习？它和无监督学习、强化学习的区别是什么？
- 监督学习的两大类任务：回归（regression）和分类（classification）

---

## 2. 本讲骨架

1. **机器学习** = 不给计算机写死规则，让它从数据里自己总结出规律。
2. **监督学习** = 数据带标准答案（有标签），学的是「输入 → 正确答案」的映射。
3. **无监督学习** = 数据没有标准答案，让算法自己从数据里找出结构（典型是「聚类」）。

---

## 3. 监督学习定义

给定训练集 $(x^{(i)}, y^{(i)})$，学习一个假设函数 $h: X \to Y$，使得 $h(x)$ 能尽可能准确地预测新样本的 $y$。



---

## 4. 回归 vs 分类

- **回归**：$y$ 是连续值（比如房价预测）
- **分类**：$y$ 是离散值（比如判断肿瘤是良性/恶性）

> **判断口诀**：答案是个「数」→ 回归；答案是个「类别」→ 分类。
> 注意：分类**不一定是两类**，也可以是多类，常记作 0/1 或 0/1/2/3。

---

## 5. 符号约定

- $m$：训练样本数量
- $x$：输入特征（feature）
- $y$：输出标签（label）
- $(x^{(i)}, y^{(i)})$：第 $i$ 个训练样本
- $h_\theta(x)$：假设函数，$\theta$ 是参数

---

## 6. 术语表

| 术语 | 英文 | 一句话定义 | 本讲的例子 | 备注 |
|---|---|---|---|---|
| 训练集 | training set | 用来「教」算法的那批数据，每条都带正确答案 | 一组「房子面积 → 实际成交价」的历史成交记录 | 后续章节会反复出现 |
| 标签 | label | 每条数据对应的「正确答案」，即算法要学着预测的东西 | 某套房子的真实成交价；肿瘤的实际诊断（良性/恶性） | 吴恩达在 1-3 里的原话是「right answers」 |
| 特征 | feature ($x$) | 描述一个样本所依据的输入属性 | 房子面积；肿瘤大小、患者年龄 | 肿瘤例子画的是「两个特征」的散点图 |
| 回归 | regression | 预测**连续数值**输出的一类监督学习任务 | 由面积预测房价，结果可以是任意实数 | 答案是个「数」→ 回归 |
| 分类 | classification | 预测**离散类别**输出的一类监督学习任务 | 判断肿瘤良性/恶性 | 类别离散，不一定是两类 |
| 聚类 | clustering | 无监督学习最典型的一类：把相似样本自动归成若干组 | 把同一事件的新闻自动聚成一堆 | 属于无监督，见第 7 节 |

## 7. 监督 vs 无监督 对比表

| 对比维度 | 监督学习 Supervised | 无监督学习 Unsupervised |
|---|---|---|
| **数据有没有「正确答案」** | 有，每条数据都带标签 | 没有，只有一堆原始数据 |
| **算法在做什么** | 学「输入 → 正确答案」的映射关系 | 自己从数据里找出隐藏的结构 |
| **输出是什么** | 连续数值（回归）或离散类别（分类） | 分组编号、数据的某种低维表示等 |
| **典型任务** | 房价预测、肿瘤良恶性判断、垃圾邮件识别 | 谷歌新闻聚类、客户分群、鸡尾酒会声音分离 |
| **代表算法** | 线性回归、逻辑回归、SVM、神经网络（后面都会学到） | K-means 聚类、ICA（独立成分分析） |
| **怎么判断效果好坏** | 有标准答案可对照——拿测试集算误差或准确率 | 没有标准答案可对照，只能看分组是否「看起来合理」，或靠业务目标间接评估 |
| **身边的例子** | 手机相册的人物识别：你先手动标了几张「这是妈妈」，手机学会后自动认出妈妈的其它照片 | 相册按人脸自动分组：没人告诉手机谁是谁，它按长得像不像把照片分成几堆 |
| **身边的例子 2** | 问诊系统：用历史上大量「症状 + 确诊结果」预测新患者的诊断 | 超市会员分群：不预设类别，按购买记录自动分出「爱买婴童用品的」「爱囤打折品的」 |
