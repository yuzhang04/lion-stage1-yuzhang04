# 代码任务②：多元线性回归 + 特征缩放 + 正规方程

> 任务书（Day6，2026-10-21）：多元线性回归 + 特征缩放（(x−mean)/std）+ 正规方程，
> 对比三种方法（无缩放 GD / 有缩放 GD / 正规方程）的收敛速度与结果。
> 产出：`multivar_regression.py` + 对比结果表。

## 一、数据

`y = 5 + 2·x1 + 3·x2 + N(0, 5²)`，m=100。

特征量级**故意拉开 20 倍**：x1∈[0,100]（std≈29.6）、x2∈[0,5]（std≈1.46）——
这正是「必须缩放」的典型场景（对应课时 4-2/4-3）。

## 二、实现思路

1. 生成数据后对 X、y 都做 Z-score 标准化 `(x - mean) / std`，统计量只从训练数据算。
2. **统一口径**：三种方法的 loss 与参数全部换算到**原始尺度**再评估——
   无缩放 GD 本来就在原始空间；有缩放 GD 每轮把参数还原（`w_j = y_std·a_j/σ_j`，
   `b = y_mean + y_std·c − Σ w_j·μ_j`）；正规方程直接就是原始尺度。
3. 收敛判据统一：`MSE ≤ J* × 1.01`，其中 J* 为正规方程解处的样本最优 MSE。
4. 正规方程用 `np.linalg.pinv` 而非 `inv`（对应课时 4-7：X^T X 不可逆时 inv 直接报错）。

## 三、验收结果（2026-10-21 实测，详见 `results.md`）

| 方法 | α | 达标轮数 | 最终 MSE | 参数 [b, w1, w2] |
|---|---|---|---|---|
| 无缩放 GD | 1e-4 | **37,180** | 23.8423 | [3.401, 1.992, 3.937] |
| 有缩放 GD | 0.1 | **22** | 23.6418 | [4.553, 1.983, 3.719] |
| 正规方程 | 无需 | **1** | 23.6418 | [4.553, 1.983, 3.719] |

- 最优值 J* = 23.6418（噪声决定的理论下限）。
- 条件数 κ(XᵀX)：未缩放 **21202.6** → 缩放后 **1.07**；α 稳定上限 0.000162 → 0.4835。
- [验证] 正规方程「不需要缩放」：原始 X 求解 vs 缩放 X 求解再还原，参数差 **4×10⁻¹²**。
- 真值 [5, 2, 3]；正规方程解与真值的差距来自噪声抽样（w2 标准误 ≈ 0.343，差 2.1 个标准误，正常）。

## 五、10-19 旧版 → 10-21 重写的四点修正

1. loss 用**更新后**的参数计算（旧版用更新前的 predictions，曲线滞后一轮）。
2. 有缩放 GD 的参数**还原回原始尺度**（旧版停在缩放空间，与真值差百倍量级）。
3. 两条 loss 曲线**统一原始尺度**（旧版一条原始一条缩放，量级差 y_std²≈3476 倍，不可比）。
4. 无缩放 GD 迭代数 100 → 40000（实测达标需 37,180 轮，旧版连 0.3% 都没跑完）。
