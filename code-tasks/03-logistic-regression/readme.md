> 任务书（Day9，2026-10-24）：纯 NumPy 实现逻辑回归（含正则化项），在二分类合成数据上
> 训练并画决策边界。产出：`logistic_regression.py` + `decision_boundary.png` + `lecture05.md`。
> 实际完成于 10-20（超前 4 天，sigmoid 与交叉熵为自学），**10-21 重写修复**三处实质问题。

## 一、实验目的
1. 不依赖 sklearn，用纯 NumPy 实现 Sigmoid、交叉熵代价函数和梯度下降。
2. 加入 L2 正则化项，**并验证它是否真的起作用**（旧版只写了代码、没验证）。
3. 在二分类合成数据上训练，画决策边界，并与理论最优边界对比。

## 二、核心公式
1. **Sigmoid**：\(h_\theta(x) = \frac{1}{1 + e^{-\theta^T x}}\)
2. **带 L2 正则化的代价**：
   \(J(\theta) = -\frac{1}{m} \sum [y \log(h) + (1-y)\log(1-h)] + \frac{\lambda}{2m} \sum_{j=1}^{n} \theta_j^2\)
   （正则化从 \(j=1\) 开始，不惩罚偏置 \(\theta_0\)）
3. **决策边界**：\(h=0.5 \iff \theta^T x = 0\)，是缩放空间中的一条直线，画图前需逆变换回原始坐标。

## 四、验收结果（2026-10-21 实测，详见 `results.md`）

**主实验**（α=1.0，5000 轮，λ=0.1）：
- θ = [-0.012, 4.117, 4.545]，与参考解差 **0.0000**
- 训练 99.50% / **测试 98.32%**；贝叶斯理论上限 98.31%（两类中心距 4.243σ）→ **已触及理论天花板**

**λ 扫描（A）原始 2 特征 / 200 样本 —— 正则化无效**：
- λ 从 0 到 100，‖θ_w‖ 从 8.59 压到 0.68，但测试 acc 只在 98.32%～98.40% 浮动，gap 恒 ≈1.1pp

**λ 扫描（B）80 样本 + 6 次多项式（27 特征，约 3 样本/特征）—— 正则化生效**：
- λ=0：训练 100.00% / 测试 97.30%，gap **2.70pp**（真过拟合）
- λ=1：训练 98.75% / 测试 98.30%，gap **0.45pp**（缩小 83%）
- λ=100：训练/测试一起崩到 42.5% → **欠拟合**（正则化过度），不是发散

## 五、结论（替代旧版无依据的推断）
- 正则化**不是万能的**：只在模型存在过拟合空间（容量相对数据量过剩）时才提升泛化。
- 原始数据 2 特征 / 200 样本 / 近线性可分，本来就没有过拟合空间，λ 扫到 100 也几乎不动。
- 判断依据是**泛化 gap（训练 acc − 测试 acc）**，不是训练准确率——后者全程 99.50%，什么都看不出来。
