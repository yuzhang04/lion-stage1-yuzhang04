# 任务1：线性回归从零实现

## 目标
用 NumPy 从零实现梯度下降，拟合 y = 4 + 3x 的线性关系。

## 实现思路
1. 生成模拟数据，加入高斯噪声
2. 在 X 前面加一列1，方便统一处理偏置
3. 用梯度下降迭代更新参数 theta
4. 记录每次迭代的 MSE 损失，画出损失曲线

## 运行方式
python linear_regression.py

## 结果
- 学到的参数：偏置≈4.0，斜率≈3.0
- 损失曲线：见 loss_curve.png，损失随迭代下降并收敛
