# 任务1：线性回归从零实现

## 一、目标
用 NumPy 从零实现梯度下降，拟合 y = 4 + 3x 的线性关系，不调用 sklearn，深入理解梯度下降的核心原理与矩阵运算。

## 二、实现思路
1. 生成 100 个模拟数据点，加入高斯噪声模拟真实数据。
2. 在 X 前面拼接一列全 1，将偏置项 b 统一到矩阵运算中（即 X_b）。
3. 零初始化参数 theta = np.zeros((2,1))（[b, w]，起点与后续任务统一，便于复现）。
4. 用梯度下降迭代 100 次更新参数：`gradients = 2/m * X_b.T.dot(predictions - y)`。
5. 记录每次迭代的真实 MSE 损失（用**更新后**的参数算，避免滞后一轮），用 matplotlib 画出损失曲线与拟合直线。
6. 用正规方程 `pinv(X_b) @ y` 交叉验证：断言 1 与精确解最大差 < 0.1；断言 2 损失全程单调下降（容差 1e-12）。

## 三、验收结果（2026-10-21 17:47 终版实跑）

**正式配置**：`seed=100`，m=100，零初始化，α=0.1，**100 轮**。

| 项 | 实测值 |
|---|---|
| 最终参数 | 截距 **3.955**、斜率 **2.889** |
| `pinv` 精确解 | 截距 3.985、斜率 2.862 |
| 与精确解最大差 | **0.03002**（判据 < 0.1，通过） |
| 最终 MSE | **1.1560**（从 17.5 单调下降，最大回升 0.00e+00） |
| α 稳定上限 | 本脚本是 MSE 口径（梯度 2/m），上限 = 1/λ_max = 1/2.0651 ≈ **0.4842**，取 α=0.1 很安全 |
| $X^\top X/m$ 特征值 / 条件数 | [0.1620, 2.0651] / κ = 12.75（很小，故本任务**不需要特征缩放**） |

> **关于轮数的取舍（实测对照，未擅自改动）**：同一份数据把轮数换成 300，参数变 3.985 / 2.862，与精确解差 **4×10⁻⁵**，MSE 1.1557 —— 多跑 200 轮（耗时可忽略）能把误差从 3×10⁻² 降到 4×10⁻⁵。当前保留 100 轮，是**判据 atol=0.1 放得较松**（实测误差只占判据的 30%）。若想让验收更硬，把 `n_iterations` 改 300、`atol` 改 0.01 即可，其余不用动。

## 四、失败实验记录（重要）
- `train_bug.log`：2026-10-09 那次 α=0.5、1000 轮的原始日志——loss 从 8.7e6 一路发散到 1.5e59。
- 根因：α=0.5 超过了稳定上限 0.4842（MSE 口径），每轮放大约 1.065 倍，几何级发散。
- 教训：**学习率 α 与目标函数曲率（Hessian 特征值）是相乘关系**，α 的可用上限由数据的特征尺度决定。
- `train_history.log`：2026-10-19 两次旧运行（当时 loss 公式写错，数值不可引用，仅留档）。
